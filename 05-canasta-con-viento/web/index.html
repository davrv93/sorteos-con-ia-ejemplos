Lo que se sortea

Cómo se juega

  1. Tienes una sola ronda de 25 segundos. Empieza a correr cuando pulsas «Empezar».
  2. Mira el viento: la flecha dice hacia dónde sopla y con qué fuerza. Cambia cada pocos segundos.
  3. Apunta al lado contrario para compensarlo: desliza la barra de puntería o usa las flechas ← →.
  4. La barra de fuerza sube y baja: tócala cuando pase por la franja amarilla.
  5. Puedes tirar cada 0,9 segundos. Si metes 6 antes de que se acabe el tiempo, el sistema sortea tu premio entre los cupos que quedan.
